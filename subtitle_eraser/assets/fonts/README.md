# Noto Sans SC

Unmodified variable font from Google Fonts, used as a redistributable Chinese
fallback for the synthetic demo, tests and portable startup check.

- Upstream: https://github.com/google/fonts/tree/a85815a42757630ce188fdad368c2dfc444d4773/ofl/notosanssc
- Original name: `NotoSansSC[wght].ttf`; packaged filename: `NotoSansSC.ttf`.
- SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`
- License: SIL Open Font License 1.1, reproduced in [OFL.txt](OFL.txt).

The project does not redistribute Windows fonts. For consistent test runs set
`SUBTITLE_ERASER_TEST_FONT` to the absolute path of this TTF before starting Python.
