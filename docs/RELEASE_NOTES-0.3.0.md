留英文 v0.3.0 · Windows 便携版
================================

在原网页或电脑播放器中观看双语视频，框选中文字幕区域，尝试去除中文字形并保留英文。处理在本机完成。

### 下载哪个文件

普通用户下载 **SubtitleEraser-0.3.0-Windows-x64.zip**，完整解压后双击 **SubtitleEraser.exe**。无需安装 Python 或开发工具。请保留同目录的 `_internal` 文件夹。

GitHub 自动提供的 `Source code (zip)` / `Source code (tar.gz)` 是源码，不能直接启动 App。

### 本版本主要变化

- 主控制窗口与 A/B/C 效果对比拆分，常用操作更集中，高级设置默认收起。
- 对比窗口支持横向并排、纵向排列、单图放大、冻结同一帧和导出快照。
- 根据显示缩放和可用工作区安排窗口，小屏幕可滚动查看设置。
- 保留低延迟中文框选、字幕样式校准、播放器设置记忆、全屏重定位和防止字幕切换露字功能。
- 框选快捷键优先使用 Ctrl+Alt+R，被占用时尝试 Ctrl+Alt+Shift+R；以界面底部显示为准。

### 第一次使用

1. 打开视频，暂停到有双语字幕的一帧。
2. 在 App 中连接播放器，使用“低延迟 · 只框中文”。
3. 框住中文及描边，避开英文，确认后切回播放器观看。
4. 查看详细步骤可打开包内 `先读我-使用说明.txt` 或 `docs/QUICK_START.md`。

### 环境与效果边界

已验证环境为 Windows 11 x64。修补依赖 CPU，不要求 NVIDIA 显卡。复杂背景可能模糊或出现接缝；不能保证无损还原、零露字或所有播放器均可捕获。独占全屏、HDR、受保护视频和 Windows 10 尚未完成全面兼容性验证。
