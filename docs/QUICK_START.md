# 留英文 0.3.0 · 使用说明

用于观看中英文双语视频时去除中文字幕、保留英文。视频仍在原来的网页或电脑客户端中播放。

## 下载与启动

1. 下载 `SubtitleEraser-0.3.0-Windows-x64.zip`，完整解压到一个文件夹。
2. 双击 `SubtitleEraser.exe`。保留同目录的 `_internal`、`licenses` 等文件夹；不要在压缩包内直接运行，也不要只复制 EXE。
3. 无需安装 Python、CUDA 或插件，正常观看时在本机处理，无需申请 API。

本次验证使用 Windows 11 x64。Windows 10、独占全屏、HDR 和受保护视频没有完成全面兼容性验证。

## 开始观看

1. 打开播放器，暂停到一帧有中英文字幕的画面。
2. 在“留英文”主窗口中选择播放器窗口，点击“连接窗口”。找不到时先恢复播放器窗口，再点“刷新”。
3. 保持“低延迟 · 只框中文”和“防止切换露字”，点击“框选 / 重新校准”。
4. 框住中文字幕及其黑色描边，上下不要包含英文，左右留出后续长句的空间。点击“使用此区域”。
5. 切回播放器继续观看。需要查看处理效果时，点击主窗口右上角“查看效果 A / B / C”。

## 全屏、快捷键与对比

- 全屏后按主窗口底部显示的框选快捷键：优先 `Ctrl+Alt+R`，被占用时自动尝试 `Ctrl+Alt+Shift+R`。
- 按 `Ctrl+Alt+H` 或点击“显示原图”可对比原画面。以界面显示的实际可用快捷键为准。
- 框选时播放器若退出全屏，确认后返回同一全屏布局，已保存的范围会恢复。若提示不能定位，先暂停到有字幕的一帧再重新框选。
- 对比窗口支持三图横排、竖排、A/B/C 单图和双击放大；关闭、最小化或冻结对比，不会停止原播放器的修补。
- 点击“停止”或退出主窗口，恢复原来的画面。

## 修补效果不合适时

- 两端仍露字：确认中文行及后续长句位于选区内，必要时重新框选。
- 有黑色描边：把完整描边包含在选区内，在“高级设置”中调整“边缘修补”。
- 字幕颜色特殊：在高级设置中尝试“校准字幕样式”，点击明亮的中文笔画，再查看轮廓和修补结果。
- 没看到叠加：确认“叠加到原播放器”已开启、当前处于连接的播放器前台，并查看底部状态提示。
- 连接后没有画面：目标可能不能被捕获，尝试普通窗口或无边框全屏并重新连接。

修补是对字幕后方背景的估计。复杂纹理、人脸、快速运动和切镜头可能出现模糊或接缝，不能保证无损还原。手动模式不判断框内语言，框入英文也可能处理英文。

## 配置与问题反馈

主动保存的设置位于 `%LOCALAPPDATA%\SubtitleEraser\profiles.json`；启动异常记录在同目录的 `runtime.log`。普通使用无需操作这些文件。

反馈问题时说明应用版本、Windows 版本、播放器、窗口化或全屏、字幕颜色，以及复现步骤。分享画面或日志前移除个人内容。源码与第三方许可见随包的 `LICENSE`、`THIRD_PARTY.md` 和 `licenses/`。
