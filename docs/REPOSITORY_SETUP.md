## 仓库名称

`subtitle-eraser`

## 简介

Windows 本地双语字幕辅助工具：框选并修补中文字幕，保留英文，在原网页或桌面播放器中继续观看。

- 主下载文件：`SubtitleEraser-0.3.0-Windows-x64.zip`
